# Supplementary Information Note 13 figures

This module renders three-dimensional GPR MAPE profiles for the five feature sets across datasets, acquisition rules and labelled-pool fractions.

## Reproduction

```bash
python "figure_generation/SI Note 13 figures (3D convergence profiles)/scripts/plot.py"
```

One trial-level CSV table is provided per feature set. The script validates the fixed experimental context and writes five 600-dpi PNG files to `outputs/`.
