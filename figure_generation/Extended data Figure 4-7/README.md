# Extended Data Figures 4–7

This module renders sample and time efficiency at NFP92, NFP95 and NFP98. For each threshold, it reports the required pool fraction, required full-life tests, total experimental duration and the duration–pool-fraction relation.

## Reproduction

```bash
python "figure_generation/Extended data Figure 4-7/scripts/plot.py"
```

Each of the 12 source tables has a same-stem rendering specification. Outputs are written to `outputs/` as 600-dpi PNG files.
